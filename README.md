# DarwinBBS daily content repair

这个补丁沿用现有 HTML/CSS/JavaScript、Supabase 和 Vercel 项目，不重建网站。

## 第一阶段完成的代码

- 活动页不再显示六张虚构的推荐样例；数据库失败、没有记录、没有符合条件的活动分别显示真实状态
- 招聘仅接收招聘方公开接口里仍在招聘、原始发布时间不超过30天的岗位，不把招聘新闻当作职位
- 自动导入的招聘和活动每次核验后保留36小时有效期；再次核验成功才刷新，避免失效信息长期留在列表
- 新闻使用原发布者三天内的标题及极短摘要，保留原文链接和原始日期，不把 RSS 片段扩写成完整报道
- 单条标题加摘录不超过25个英文词，不自动复制第三方图片
- 按原始来源、岗位重发日期、活动场次去重；同类任务使用互斥锁；数据库去重记录失败时停止发布
- 保留现有论坛、手动招聘和手动新闻，不生成虚假用户、评论、阅读量或社区活跃度
- 论坛加入真实讨论标题、全文搜索、分页加载、清楚的加载失败与重试状态，以及社区交流与隐私提醒；原有帖子和评论继续保留
- 修复论坛列表将用户内容和图片地址直接插入 HTML 的问题；登录中断或提交失败时保留草稿，防止连续点击重复提交

## 当前来源范围

1. 招聘：Sodexo、Minor Hotels、Accor 公开招聘 API；包含符合定位条件的 Darwin、Gove/Nhulunbuy 等北领地岗位
2. 活动：City of Darwin 主办方活动页，要求可核验的地点、开始与结束时间
3. 新闻：ABC NT 原始文章日期及 NT 相关性检查；City of Darwin 新闻

这是已验证的起步来源集，不代表覆盖北领地全部信息，也没有声称这些活动按实时人气排名。英文原标题暂时保留。OpenAI API 不参与这一阶段，因此不需要新增 OpenAI API 费用。翻译需要另行配置并确认预算。

涉及个人严重指控等高影响新闻，自动流程先排除并记录审核原因。关键词门槛是保守辅助措施，不能替代后续人工编辑与社区举报管理。

## 本地验证

```sh
npm ci --ignore-scripts
npm test
npm run check
npm run verify:sources
```

`verify:sources` 仅以 GET 读取固定官方来源，不连接 Supabase、不写入任何网站。来源超时或部分失败时退出码为2并输出具体诊断；没有合格内容时不会造数据填充。也可指定一个类别：`npm run verify:sources -- jobs`。

## 上线状态

代码和测试准备完成不等于已上线。需完成 [上线核验清单](docs/operations.md)。当前准备阶段未修改生产数据库、RLS、密钥、Vercel 环境变量或部署。

现有 Vercel 计划不变：达尔文时间每天07:30新闻（最多3条）、07:50招聘（最多5条新增，已存在的合格职位也会刷新）、08:10活动（最多8条新增）。具体执行是否成功必须查生产任务记录，不以配置文件代替运行证据。

## 后续 BBS 阶段

基础讨论体验已改进。下一步检查现有登录/发帖/评论权限，加入真正可追踪的举报、审核和服务端反垃圾功能，再扩展信息分类与更多经验证来源。现有社区提醒页面不替代数据库权限或完整隐私政策。这些不能靠伪造互动或开放匿名管理员写权限实现。
